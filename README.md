# Choisis le bon capteur

Jeu pédagogique sur les capteurs industriels pour la formation professionnelle en électromécanique et en électricité.

- **Session 1 : choisir le capteur.** L'élève choisit un objet, une distance, un environnement et un besoin, puis un capteur parmi 9 (inductif, capacitif, photoélectrique en barrage, réflex et diffus, ultrasonique, magnétique, fin de course, laser de distance). Une tour lumineuse donne le verdict : vert, jaune ou rouge, avec une explication.
- **Missions** : 14 situations d'usine notées.
- **Session 2 : brancher le capteur.** PNP/NPN, NO/NF, sortie 4-20 mA, branchement fil par fil sur un banc, avec simulation de l'entrée de l'automate. 13 missions notées.
- Les 9 fiches de capteurs sont intégrées.
- Fonctionne sur ordinateur, tablette et téléphone, même sans Internet une fois installé.

## Installer l'application

- **Android (Chrome)** : ouvrir la page, puis le bouton « 📲 Installer l'application » ou le menu ⋮ → *Installer l'application*.
- **iPhone / iPad (Safari)** : ouvrir la page, puis Partager → *Sur l'écran d'accueil*.
- **Ordinateur (Chrome / Edge)** : icône d'installation à droite de la barre d'adresse.

## Mettre à jour

1. Remplacer les fichiers dans le dépôt.
2. Changer le numéro de version et la date au bas de `index.html` (ligne `Version …`).
3. Changer le même numéro dans `sw.js` (`capteurs-v1.1` → `capteurs-v1.2`, etc.).
4. Noter les changements dans `CHANGELOG.md`.

Les appareils reçoivent la nouvelle version à la prochaine ouverture avec Internet.
